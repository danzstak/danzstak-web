# Self-hosted EPK typefaces

These WOFF2 files are self-hosted so public EPKs make no third-party font request. The families are Archivo, JetBrains Mono, Anton, Special Elite, Work Sans, Pirata One, Oswald, Source Serif 4, Syne and DM Sans from the Google Fonts catalog. Each is distributed under the SIL Open Font License 1.1; upstream family metadata and license texts remain available from the corresponding family directory in [google/fonts](https://github.com/google/fonts).

Only the Latin webfont subset and the weights used by the four EPK looks are stored here. Browsers fall back to the system font for characters outside that coverage.
