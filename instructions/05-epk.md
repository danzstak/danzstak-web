# 05 — Electronic press kit

Provide artist-editable biography, press photos, logos, release links, performance information, and a professional shareable EPK view for agents/managers. Include upload/management for image assets, permission controls, size limits, and removal. For videos, use externally hosted embeds/links by default to avoid unplanned hosting costs; request approval before introducing video-file storage.

**Acceptance:** create/edit/save/reload/share EPK, verify authorization and upload constraints, test mobile view, and report hosting/storage costs.
