# Landing page — featured DJ mix without redesign

## Owner direction
The existing DANZSTAK landing page is approved visually. **Do not redesign or replace it.** Add a prominent, high-quality featured DJ mix experience that fits the existing design and welcomes new visitors into the music culture.

## Required behavior
- Reuse the existing landing page structure, branding, CTAs and authentication flow.
- Feature one owner-approved externally hosted DJ mix with artwork, track/mix title, artist credit, obvious Play/Pause control and visible Join DANZSTAK CTA.
- Do not invent or choose an unapproved copyrighted mix, upload audio to DANZSTAK, or change hosting infrastructure.
- Browser policies: do not promise audible autoplay; start audio after explicit user Play action. No overlapping audio with feed videos or other media; stop on navigation or player close.
- Keep loading fast on mobile; defer media until needed, show graceful fallback if external embed fails.
- Accessible controls, responsive layout at 360/390px and desktop.
- Inspect existing landing implementation before modifying; preserve current layout and copy except for approved mix placement.

## Acceptance
Provide before/after screenshots, playback and navigation tests, external provider limitations, PR and verified PWA preview. No production deployment without owner approval.
