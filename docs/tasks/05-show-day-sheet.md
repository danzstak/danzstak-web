# Task 05 — Advance sheet + show day sheet (crew-grade)

## Owner background
Shawn is a 25+ year IATSE Local 16 stagehand. This must be something a real production manager and house crew can work from.

## Build
1. **Advance** for each confirmed show: load-in, soundcheck, doors, set time + length, curfew, venue PM/contact, parking/load-in door, backline (provided vs. bringing), power, house crew/union notes, hospitality, guest list count, merch split, settlement method. Pre-fills from the deal (task 02) and the EPK stage plot / input list / rider.
2. **Send advance to the venue** through the booking mail bridge (replies → SYNC). Venue can reply with corrections; the artist updates fields.
3. **Day sheet**: one phone page per show day — times in order, address with map link, contacts (tap to call/email), backline, set list slot, plus Town plan items (in-store, radio). Printable (1 page). Shareable to band/crew by private link (no login), revocable.
4. Settlement (existing close-out) pre-fills from the deal.

## Tests
Times in order and in the venue's time zone; private share link revocable; print fits one page; no personal phone numbers exposed beyond what the artist enters.
