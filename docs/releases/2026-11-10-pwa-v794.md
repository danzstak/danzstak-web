# PWA v794 — mobile Profile post contract

Status: **release candidate; deployment pending required GitHub review checks**.

## Scope

- Profile only. Mix, Stores, SYNC, payments, authentication and backend behavior are unchanged.
- Mobile Profile canvas uses `#F0F2F5` so the 8px separation between posts is visible.
- Profile posts are solid white, square-edged and shadow-free on phones.
- Post text and identity content use 12px vertical / 16px horizontal padding.
- Author avatars are 40px circles with a 12px author-name gap.
- Images and videos break through the text gutters and visibly reach both phone edges.
- The action row follows the media by 12px, starts with a 1px `#CED0D4` divider and retains 44px targets.
- The official DanzStak account and member accounts use the same shared Profile renderer.
