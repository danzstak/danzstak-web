# PWA v795 — complete Profile interactions

Status: **implemented and tested; production unchanged pending the green review gate**.

## Scope

- Profile only. Mix, Stores, SYNC, Booking, EPK, payments, authentication and backend infrastructure are unchanged.
- The Profile navigation is a familiar 44px row with **Posts**, **About**, **Photos**, **Videos** and **More**. Photos and Videos filter real profile posts; More retains Featured, Memories, Friends, Media and the member Shop.
- Owners receive a compact create-post utility with their signed avatar, text, existing photo/video upload flow, audience selection and original-content certification. **Life Event** opens the existing event workflow; no fake live-stream control was added.
- Every rendered Profile post now has a compact author header, real reaction/comment counts, working Like, Comment and Share controls, and the existing owner tools.
- Comments use 32px author images, 18px bubbles, reply/delete actions on one line, and 24px reply images at a 40px nested indent. Comment posting, replying, reaction and owner deletion use the existing authenticated APIs.
- The official DanzStak account and ordinary members use the same Profile renderer.
