# DanzStak Android test build

`danzstak-android-test.apk` is a development build for owner-authorized physical-device testing. It is not the finished production release.

- Version: `0.1.1` (`versionCode 2`)
- SHA-256: `6C92418420E198F93FD0B837F947D11174142E3E79F75D5245FDA07DAB8BD5CA`
- Features: secure browser login, Android Keystore session protection, native photo/video feed, text posting, and logout
- Site integration: identifies the installed DanzStak app to supported Android browsers so duplicate install prompts can be suppressed

The production package will use the stable `/downloads/danzstak-android.apk` path after owner-controlled release signing and physical-device verification.
